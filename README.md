# Puntr AI Insights

Build a premium, production-ready SaaS web application called Puntr — South Africa’s #1 AI-powered betting prediction and community platform.

Website: https://punthub.fun

Puntr aggregates betting markets, odds, predictions, AI insights and community picks from South Africa’s leading bookmakers while rewarding users with PuntPoints and a 30% recurring referral commission for every Premium subscriber they refer.

The platform should feel like a hybrid between:

* Scoutr
* Duolingo
* Reddit
* TradingView
* Sofascore
* Dribbble-quality SaaS dashboards

The experience must be exceptionally polished, responsive, fast and visually premium.

⸻

IMPORTANT DESIGN REQUIREMENT

Use every supplied desktop and mobile mock-up image as the primary UI/UX reference.

Do not redesign the layouts.

Instead:

* recreate the visual design system
* recreate the spacing
* recreate the typography
* recreate the card layouts
* recreate the navigation
* recreate the information hierarchy
* recreate the mobile layouts
* improve interactions and animations where appropriate

The final result should feel almost identical to the supplied mockups while being production ready.
