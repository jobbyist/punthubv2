# Glossary

Fixed terms. Reviewers fill the three right-hand columns; the English column is the source of truth. Do not translate: **Puntr, PuntPoints, team names, competition names, bookmaker names, "1X2"**.

| English (en-ZA)      | Afrikaans | isiZulu | isiXhosa | Notes                                            |
| -------------------- | --------- | ------- | -------- | ------------------------------------------------ |
| pick                 |           |         |          | A single prediction a member posts and locks.    |
| tipster              |           |         |          | A member who posts picks. Not an adviser.        |
| kick-off             |           |         |          | The scheduled start time; picks lock here.       |
| full time            |           |         |          | End of normal play, used for grading.            |
| accumulator ("acca") |           |         |          | Several selections combined into one bet.        |
| Match result (1X2)   |           |         |          | Keep "1X2" as written.                           |
| Double chance        |           |         |          |                                                  |
| Handicap             |           |         |          | Rugby only at launch.                            |
| Both teams to score  |           |         |          | Soccer only at launch.                           |
| Over/Under           |           |         |          | Total goals line, 2.5 at launch.                 |
| units                |           |         |          | Stake-neutral measure: every pick is 1 unit.     |
| record               |           |         |          | The public history of a member's picks.          |
| locked               |           |         |          | Cannot be edited or deleted.                     |
| Founding Member      |           |         |          | One of the first 100 members. Capitalised.       |
| take a break         |           |         |          | Responsible-gambling pause. Must be unambiguous. |
| responsible gambling |           |         |          | Review with the helpline wording in `rg.json`.   |

Style notes for reviewers: plain, direct tone; no slang; money is always `R1 234,50` and odds `2.10` in every language; the helpline is `0800 006 008` in every language; dates `Sat 31 Oct 2026` and 24-hour times with "SAST" (translate the weekday and month names only).
