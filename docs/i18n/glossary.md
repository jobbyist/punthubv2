# Glossary

Fixed terms. The Afrikaans column is a first draft for the native-speaker reviewer to confirm in Admin > Translations; isiZulu follows later (isiXhosa was removed from the plan, 14 Nov 2026). Reviewers fill the language columns; the English column is the source of truth. Do not translate: **Puntr, PuntPoints, team names, competition names, bookmaker names, "1X2"**.

Style notes for reviewers: plain, direct tone; no slang; money is always `R1 234,50` and odds `2.10` in every language; the helpline is `0800 006 008` in every language; dates `Sat 31 Oct 2026` and 24-hour times with "SAST" (translate the weekday and month names only).


More Afrikaans choices used in the draft: prediction = voorspelling, leaderboard = ranglys, odds = prys/pryse, settled = afgehandel, void = nietig, ROI = opbrengs (ROI), Practice Mode = Oefenmodus, Founding Annual Pass = Stigters-jaarpas, Pay-As-You-Go = betaal soos jy gebruik, quest = taak, wallet = beursie, voucher = koopbewys, sign in = teken aan, sign up = registreer / sluit aan.
